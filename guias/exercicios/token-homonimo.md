# Como verificar se dois tokens com o mesmo símbolo são iguais?

**Exercício.** Dois ativos exibem a mesma sigla na Base. O que você compara?

**Resposta.** Compare o endereço do contrato de cada ativo com o divulgado pela fonte oficial do emissor.

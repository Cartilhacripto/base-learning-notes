# Como identificar a rede de uma operação?

**Exercício.** A carteira informa Base Mainnet, mas o link abre um explorador da Ethereum. Onde você procura o hash?

**Resposta.** No explorador da Base Mainnet. Corrija a rede antes de concluir que a operação não existe.

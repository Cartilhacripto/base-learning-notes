# Como montar um registro de operações?

**Exercício.** Você precisa documentar uma transferência para consultar depois. Quais dados anotar?

**Resposta.** Guarde rede, hash, data com fuso, ativo, quantidade, taxa e finalidade. Separe a taxa do valor movimentado.

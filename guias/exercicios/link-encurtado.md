# Como lidar com um link encurtado de suposto suporte?

**Exercício.** Uma mensagem diz que você precisa abrir um link para resgatar uma transferência. Como prosseguir?

**Resposta.** Abra o suporte pelo endereço oficial já conhecido e localize a operação pelo hash. Evite conectar a carteira pelo link da mensagem.

# Como distinguir duas transferências iguais?

**Exercício.** Uma carteira enviou a mesma quantia duas vezes para o mesmo destino. Qual campo distingue os pagamentos?

**Resposta.** O hash. Compare também o bloco e a hora de inclusão se precisar identificar qual veio primeiro.

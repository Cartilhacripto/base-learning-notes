# Quem recebe a permissão de gasto?

**Exercício.** Uma carteira mostra o contrato do token e outro endereço como spender. Qual deles é o autorizado a gastar?

**Resposta.** O spender. O contrato do token registra a permissão. Confira a identidade do spender antes de autorizar.

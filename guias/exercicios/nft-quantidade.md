# Como ler uma transferência ERC-1155?

**Exercício.** O evento mostra token ID 7 e quantidade 3. O que foi transferido?

**Resposta.** Três unidades do item identificado por 7 naquele contrato. A quantidade não representa três identificadores diferentes.

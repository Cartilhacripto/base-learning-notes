# Quando o campo To é um contrato?

**Exercício.** Uma transação aponta para um endereço com código implantado. O que verificar antes de atribuir o valor a uma pessoa?

**Resposta.** Abra a página do contrato e examine os movimentos da operação. Um contrato chamado pela carteira pode redistribuir ativos para outros endereços.

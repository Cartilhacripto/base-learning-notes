# CartilhaCripto · Aprenda a usar a Base

Guias e exercícios em português para quem está dando os primeiros passos em cripto. Aprenda como funcionam as carteiras, de onde vêm as taxas e como conferir uma transação na rede Base.

## Comece por aqui

1. [**Primeiros passos na Base**](guias/primeiros-passos/README.md) — Consulte 43 notas curtas sobre carteiras, tokens, taxas e operações na rede.
2. [**Como consultar uma transação na Base**](guias/como-consultar-uma-transacao-na-base.md) — Encontre uma transação pelo hash e confira o status, o destinatário e a taxa no explorador.
3. [**Exercícios práticos com respostas**](guias/exercicios/README.md) — Pratique com 49 situações, como identificar a rede de um depósito ou interpretar os dados de uma troca de tokens.

## Diário de aprendizagem

**Dia 1.** Estudei a rede Base e fiz um swap (troca de ativos) e usei uma bridge (ponte entre redes).
